# نادي شعب حضرموت - Android wrapper

This Android project packages the approved HTML/CSS/JavaScript PWA as a standalone Android app named **نادي شعب حضرموت**.

## Build APK

1. Push this project to a GitHub repository.
2. Open **Actions → Build Android APK → Run workflow**.
3. Download the `Shaab-Hadramout-APK` artifact and extract `app-debug.apk`.

The original web app files are copied unchanged into `app/src/main/assets/`.
